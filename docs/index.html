DarBot Webview UI Toolkit

Retro Cyber Modern Design System for VS Code

An unofficial continuation of Microsoft's deprecated VSCode Webview UI Toolkit. Build stunning webview-based VS Code extensions with web components, React wrappers, and automatic theme support. Modern, accessible, and developer-friendly.

Powerful Features

🎨

VS Code Design Language

All components follow Visual Studio Code's design language, ensuring seamless integration with the editor's look and feel.

🌈

Automatic Theme Support

Components automatically adapt to VS Code's color themes, supporting light, dark, and high-contrast modes out of the box.

⚡

Web Components

Built with web standards. Use with any framework - React, Vue, Svelte, Angular, or vanilla JavaScript.

♿

Accessibility First

ARIA labels, keyboard navigation, and screen reader support included by default. WCAG 2.1 compliant.

🚀

Performance Optimized

Lightweight, tree-shakeable components with minimal runtime overhead. Perfect for VS Code webviews.

🔧

Developer Friendly

TypeScript support, comprehensive documentation, and extensive sample extensions to get you started quickly.
