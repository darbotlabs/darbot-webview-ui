Getting Started Guide

This guide will walk you through creating a webview-based VS Code extension with the DarBot Webview UI Toolkit. Follow these steps to get up and running quickly.

Quick Start

If you already have a webview-based extension, you can install the toolkit with a single command:

npm install --save darbot-webview-ui
💡 Pro Tip: Check out our sample extensions for pre-configured starter templates with various frameworks including React, Vue, Svelte, Angular, and more!

Part 1: Create a Webview Extension

Before using the toolkit, you need a webview-based extension. We'll use Yeoman and the VS Code Extension Generator.

Prerequisites

  • Node.js (v14 or higher)
  • Git
  • Visual Studio Code

Install Generator

npm install -g yo generator-code

Generate Extension

yo code

# ? What type of extension do you want to create? New Extension (TypeScript)
# ? What's the name of your extension? hello-world
# ? What's the identifier of your extension? hello-world
# ? Initialize a git repository? Yes
# ? Which package manager to use? npm

Part 2: Install the Toolkit

Navigate to your extension directory and install the DarBot Webview UI Toolkit:

cd hello-world
npm install --save darbot-webview-ui

Part 3: Set Up Your Webview

Create a simple webview that uses the toolkit components.

1. Register Components

In your webview JavaScript/TypeScript file, import and register the components you need:

import {
  provideVSCodeDesignSystem,
  vsCodeButton,
  vsCodeTextField,
  vsCodeCheckbox
} from 'darbot-webview-ui';

// Register components
provideVSCodeDesignSystem().register(
  vsCodeButton(),
  vsCodeTextField(),
  vsCodeCheckbox()
);

2. Use Components in HTML

Now you can use the web components in your webview HTML:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Hello World</title>
</head>
<body>
    <h1>Hello from DarBot Webview UI!</h1>
    
    <vscode-text-field placeholder="Enter your name"></vscode-text-field>
    <vscode-checkbox>Enable notifications</vscode-checkbox>
    <vscode-button>Click Me!</vscode-button>
    
    <script src="main.js"></script>
</body>
</html>

3. Message Passing

Set up communication between your extension and webview:

// In your webview
const vscode = acquireVsCodeApi();

document.querySelector('vscode-button').addEventListener('click', () => {
  vscode.postMessage({ command: 'hello' });
});

// In your extension
panel.webview.onDidReceiveMessage(
  message => {
    switch (message.command) {
      case 'hello':
        vscode.window.showInformationMessage('Hello from webview!');
        break;
    }
  }
);
⚠️ Important: All toolkit components automatically inherit VS Code's current theme. No additional configuration needed for theming!
