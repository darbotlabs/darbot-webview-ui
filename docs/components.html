Component Library

A comprehensive collection of VS Code-themed components for building beautiful webview extensions. All components support automatic theming and are fully accessible.

📝 Form Components

🔘

Button

Clickable button component with primary, secondary, and icon variants. Supports appearance customization and disabled states.

<vscode-button>Click Me</vscode-button>
📖 Docs 🎨 Demo
☑️

Checkbox

Standard checkbox for boolean input. Supports checked, indeterminate, and disabled states with customizable labels.

<vscode-checkbox>Accept terms</vscode-checkbox>
📖 Docs 🎨 Demo
🔽

Dropdown

Select input with customizable options. Supports single selection, positioning, and keyboard navigation.

<vscode-dropdown> <vscode-option>Option 1</vscode-option> </vscode-dropdown>
📖 Docs 🎨 Demo
📻

Radio & Radio Group

Radio buttons for mutually exclusive selections. Group component manages state across multiple radio options.

<vscode-radio-group> <vscode-radio>Option A</vscode-radio> <vscode-radio>Option B</vscode-radio> </vscode-radio-group>
📖 Docs 🎨 Demo
✏️

Text Field

Single-line text input with placeholder support. Includes variants for email, password, and other input types.

<vscode-text-field placeholder="Enter text"></vscode-text-field>
📖 Docs 🎨 Demo
📝

Text Area

Multi-line text input for longer content. Supports resize, placeholder, and row customization.

<vscode-text-area rows="4"></vscode-text-area>
📖 Docs 🎨 Demo

🎨 Display Components

🏷️

Badge

Small status indicators and notification badges. Perfect for counts, labels, and status displays.

<vscode-badge>12</vscode-badge>
📖 Docs 🎨 Demo
🔗

Link

Hyperlink component with VS Code styling. Supports external and internal navigation.

<vscode-link href="https://example.com">Click here</vscode-link>
📖 Docs 🎨 Demo
🏷️

Tag

Dismissible tag component for labels and categories. Supports custom colors and removable functionality.

<vscode-tag>TypeScript</vscode-tag>
📖 Docs 🎨 Demo
➖

Divider

Horizontal or vertical divider for separating content sections. Customizable orientation and styling.

<vscode-divider></vscode-divider>
📖 Docs 🎨 Demo

📐 Layout Components

📋

Panels

Collapsible panel container for organizing content. Supports expand/collapse with header customization.

<vscode-panels> <vscode-panel-tab>Tab 1</vscode-panel-tab> <vscode-panel-view>Content</vscode-panel-view> </vscode-panels>
📖 Docs 🎨 Demo
📊

Data Grid

Powerful table component with sorting, selection, and custom templates. Perfect for displaying structured data.

<vscode-data-grid></vscode-data-grid>
📖 Docs 🎨 Demo

🔄 Feedback Components

⭕

Progress Ring

Circular progress indicator for loading states. Supports determinate and indeterminate modes.

<vscode-progress-ring></vscode-progress-ring>
📖 Docs 🎨 Demo
